# Jerzy MultiFX GUI3D library

The production library is generated by `scripts/generate_gui3d_assets.py` from the approved visual direction. It contains separate transparent assets rather than screenshots of the interface:

- `knobs/`: master, FX and selector families; five accents; 101 frames per strip,
- `shadows/`: one static transparent shadow per knob family,
- `switches/`: off, on, hover, pressed and disabled states,
- `lights/`: off/on LED states,
- `panels/`: dark brushed chassis and module textures,
- `meters/`: VU face, needle and glass layers,
- `asset_manifest.json`: dimensions, pivots, frame counts and SHA-256 checksums.

All text stays live and is drawn by JUCE. The images do not receive mouse input. Existing `juce::Slider` and routing components remain the interaction and VST3 automation layer. The design surface is fixed at 1280×720 and scales uniformly to the host viewport.

The source concept atlases are not redistributed. The checked-in production sprites are a deterministic procedural recreation and can be regenerated with Pillow 12 or newer.

## Rack Hybrid — all editor pages (2026-11-06)

The approved hardware-style Rack Hybrid is now the shared visual system
for the **entire** VST3 editor, not just the home screen:

- Home: four simultaneously visible live FX, analog VU input/output, trim knobs, routing and chain.
- Drive/preamp: preamp, tape drive, drive, compressor, and their paginated parameter controls.
- Modulation: Chorus, Attack/Decay, Atomic Cluster, including advanced controls.
- Delay A/B: hardware-style bank selector, model picker, dynamic DSP engine
  controls, routing buttons, dual-time/feedback knobs; detailed/advanced MD view.
- Reverb: engine-specific parameters, pagination and master section.
- CAB/IR: impulse response, cabinet parameters and file-loading controls.
- Global settings, presets and master actions: the same graphite/metal material,
  readable state feedback and no duplicate title/footer pass.

The UI keeps the existing hit boxes and parameter automation mapping. This is
intentional: no DSP engine, VST3 identifier, preset format or project state is
replaced by a drawn placeholder.

Validation: `EditorSmoke.cpp` now physically navigates all five block pages,
seven Drive/Modulation sections, Delay Advanced and global settings, and writes
real-DLL BMP screenshots (first test cycle) for visual inspection. CI green
does not constitute visual acceptance; inspect those screenshots at 960x540
on CI and the normal editor geometry at 1280x720.

The previously working Rack Hybrid home build is the functional baseline.
Do not merge changes solely on attractive screenshots: native mouse, right-click
reset, Shift-right-click MIDI Learn, routing and automation tests must pass too.
